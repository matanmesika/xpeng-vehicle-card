# Security policy

This is a **read-only, frontend-only** Home Assistant card, independent of the XPENG Direct integration. It must never handle XPENG passwords, bearer tokens, account credentials, or custom cloud endpoints.

Do not add vehicle command endpoints or transmit sensitive telemetry to third parties. Source mappings are best-effort placeholders, not API claims. Report security vulnerabilities privately through GitHub's **Report a vulnerability** feature if enabled, or to the repository maintainer by a private contact method rather than public issues. Avoid publishing VINs, location histories, real API responses, or credentials in bug reports.

This prerelease has not undergone a third-party security audit or real Home Assistant end-to-end testing.
