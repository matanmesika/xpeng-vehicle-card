# דשבורד XPENG — גרסה 0.1.0

זהו פרויקט **דשבורד בלבד** ל־Home Assistant, הנפרד לחלוטין מאינטגרציית XPENG. האינטגרציה אחראית על התקשורת עם הרכב ועל יצירת חיישנים וישויות. הדשבורד אחראי **לתצוגה בלבד** וקורא מידע מהישויות שכבר קיימות.

## שני המסכים היחידים

1. **מצב הרכב (Vehicle status):** תמונת רכב גדולה, מצב הסוללה, טווח נסיעה, קילומטראז׳, לחץ צמיגים ומיקום.
2. **טעינה (Charging):** תמונת רכב בעמדת טעינה, מצב הסוללה, הטווח, הספק הטעינה, הזמן שנותר ויעד הטעינה.

המעבר למסך הטעינה מתבצע אוטומטית כאשר `binary_sensor.<prefix>_is_charging` משנה מצב ל־`on`, ובחזרה למסך הרכב כאשר הוא `off`. ניתן לעבור למסך מצב הרכב בלחצן Home. לחצן המסך המלא מרחיב את התצוגה.

כל המסכים הישנים — אקלים, דלתות, מושבים, שליטה, מזג אוויר ותפריטים נוספים — הוסרו מהכרטיס הפעיל. הגדרות הדגם והצבע נעשות **רק בעריכת הכרטיס**, ולא במסך נוסף.

## התקנה באמצעות HACS

הוספת מאגר מותאם אישית בקטגוריית Dashboard:
`https://github.com/matanmesika/xpeng-vehicle-card`

הגדרת הכרטיס:

```yaml
type: custom:xpeng-vehicle-card
prefix: my_xpeng
model: G6
year: '2026'
trim: core_plus_rwd
color: arctic_white
grid_options:
  columns: full
  rows: auto
```

קובץ הגדרות לדשבורד רחב: [xpeng-g6-cockpit.yaml](dashboards/xpeng-g6-cockpit.yaml).

**אין נתונים מדומים.** ערכים שאינם מסופקים מחיישני Home Assistant יוצגו בתור —. המערכת אינה מפעילה פקודות על הרכב. התמונה ועמדת הטעינה הם עיצוב בלבד.

גרסת **Dashboard 0.1.0** אינה מספר הגרסה של האינטגרציה. הקוד והנתונים של האינטגרציה נשארים ללא שינוי.
