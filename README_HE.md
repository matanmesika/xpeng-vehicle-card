# דשבורד XPENG — Home Assistant

כרטיס תצוגה עצמאי של רכבי XPENG ל־Home Assistant. **המאגר הזה כולל רק את הדשבורד (Frontend)**. הוא לא משנה את אינטגרציית XPENG ולא שולח פקודות לרכב.

**מצב הגרסאות:** הגרסה האחרונה שפורסמה ב־HACS היא [v1.0.0-alpha.5](https://github.com/matanmesika/xpeng-vehicle-card/releases/tag/v1.0.0-alpha.5). השינויים החדשים נשמרים ב־[PR #21](https://github.com/matanmesika/xpeng-vehicle-card/pull/21) ונמצאים בבדיקת פיתוח; הם **עדיין לא פורסמו ל־HACS**.

## המראה שהוגדר

- **רקע קבוע מאושר**: הבית, האגם וההרים בלילה. תמונת הרכב נפרדת מהרקע ואפשר להחליף רק את הרכב.
- **מצב הרכב**: רכב במרכז, סוללה וטווח נסיעה, קילומטראז׳, מיקום ולחצי צמיגים.
- **מצב טעינה**: מופיע אוטומטית רק כשהחיישן של Home Assistant מדווח על טעינה פעילה. הרקע נשאר זהה.
- **לחצי צמיגים**: בלחיצה על שורת Tire pressure במצב הרכב, מרכז התצוגה עובר למבט־על גדול עם ארבעה ערכים אמיתיים ליד הגלגלים. בלחיצה על Back to vehicle חוזרים למצב הרכב.
- **שורת הכותרת**: סמל רשת, מצב חיבור (מחובר / לא מחובר / שגיאת חיבור) ואייקון מידע סמוך באותה שורה.
- **חלונית מידע**: סגורה כברירת מחדל. **רק לחיצה על אייקון המידע** פותחת חלונית עם שני פרטים: Connection ו־Last vehicle update. לחיצה נוספת סוגרת אותה. לא מופיעים בה תמונת פנים, דגם, גימור, צבע או פרטים אחרים.

## כלל התמונות — דגם וצבע בלבד

**לכל דגם מופיעה תמיד תמונה אחת של רמת הגימור הגבוהה ביותר שקיימת במאגר התמונות, ללא קשר לשנה או לגימור שנבחר.**

| בחירה | השפעה |
| --- | --- |
| דגם | בוחר משפחת תמונות של רכב |
| צבע חוץ | משנה את תמונת הרכב |
| שנתון | משנה **רק** את רשימת שמות רמות הגימור |
| רמת גימור | מידע בלבד; אינה משנה תמונה, צבע או חיישנים |
| צבע פנים | הגדרה נפרדת בעורך הכרטיס; אינו מופיע בחלונית המידע |

כך למשל G6 לבן מ־2023 ומ־2026 מציגים אותה תמונה. נכון לעכשיו G6 משתמש בנכס `core_performance_awd` ו־G9 בנכס `performance_awd`. **התמונות עדיין בגדר הדמיות שאינן מאומתות כתמונות יצרן של הגימור הגבוה**, ובחלק מהדגמים נעשה שימוש בתמונה כללית מסומנת. עדיין חסרות תמונות שקופות מקוריות של אחוריים ומבט־על. הרקע המאושר נשאר ללא שינוי.

## התקנה

ב־HACS → Custom repositories הוסיפו את המאגר `https://github.com/matanmesika/xpeng-vehicle-card` כ־**Dashboard**. התקינו את הגרסה שפורסמה וטענו מחדש את Home Assistant.

```yaml
type: custom:xpeng-vehicle-card
prefix: my_xpeng
model: G6
year: "2026"
trim: core_plus_rwd
color: arctic_white
interior: light_gray
grid_options:
  columns: full
  rows: auto
```

הגדרת דגם, שנתון, גימור וצבע מתבצעת **רק בעריכת הכרטיס**. בעורך קיימת אפשרות למיפוי אוטומטי לפי `prefix` או למיפוי ידני של 15 שדות מתוך ישויות Home Assistant, כולל שילוב חיישנים מאינטגרציות שונות. ניתן לקרוא גם מאפיין של ישות באמצעות `entity_id|attribute_name`.

הנתונים בכרטיס אינם מומצאים: בהיעדר חיישן תקין יוצג — או מצב לא זמין. לחץ הצמיגים מפורט לפי ארבע פינות הרכב; סוללה, טעינה, מיקום וזמן העדכון מתקבלים רק מנתוני Home Assistant.
