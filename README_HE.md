# דשבורד XPENG — תצוגת פיתוח 0.1.2

זהו פרויקט **דשבורד בלבד** ל־Home Assistant, הנפרד לחלוטין מאינטגרציית XPENG. האינטגרציה אחראית על התקשורת עם הרכב ועל יצירת חיישנים וישויות. הדשבורד אחראי **לתצוגה בלבד** וקורא מידע מהישויות שכבר קיימות.

## שני המסכים היחידים

1. **מצב הרכב (Vehicle status):** תמונת רכב גדולה, מצב הסוללה, טווח נסיעה, קילומטראז׳, לחץ צמיגים ומיקום.
2. **טעינה (Charging):** תמונת רכב בעמדת טעינה, מצב הסוללה, הטווח, הספק הטעינה, הזמן שנותר ויעד הטעינה.

מסך הטעינה מופיע **רק כשחיישן הטעינה מצביע על טעינה פעילה** (`on`, `charging` ועוד מצבים חיוביים מוכרים). כשהטעינה מסתיימת, מושהית, לא זמינה או שהכבל רק מחובר — מופיע מסך מצב הרכב. אין מעבר ידני למסך טעינה. **לחצן הבית והשעון הוסרו**; כפתור המסך המלא נשאר.

כל המסכים הישנים — אקלים, דלתות, מושבים, שליטה, מזג אוויר ותפריטים נוספים — הוסרו מהכרטיס הפעיל. הגדרות הדגם, השנתון, רמת הגימור וצבעי הרכב והפנים נעשות **רק בעריכת הכרטיס**, ולא במסך נוסף. בהגדרות הכרטיס ניתן לבחור מיפוי אוטומטי לפי קידומת, או למפות ידנית כל אחד מ־15 השדות לישות מכל אינטגרציה ב־Home Assistant. אפשר לערבב מיפוי אוטומטי וידני. לשימוש במאפיין של ישות, ניתן לכתוב `sensor.example|battery_level`.

## התקנה באמצעות HACS

הוספת מאגר מותאם אישית בקטגוריית Dashboard:
`https://github.com/matanmesika/xpeng-vehicle-card`

הגדרת הכרטיס:

```yaml
type: custom:xpeng-vehicle-card
prefix: my_xpeng
model: G6
year: '2026'
trim: core_plus_rwd
color: arctic_white
grid_options:
  columns: full
  rows: auto
```

קובץ הגדרות לדשבורד רחב: [xpeng-g6-cockpit.yaml](dashboards/xpeng-g6-cockpit.yaml).

**אין נתונים מדומים.** ערכים שאינם מסופקים מחיישני Home Assistant יוצגו בתור —. המערכת אינה מפעילה פקודות על הרכב. התמונה ועמדת הטעינה הם עיצוב בלבד.

גרסת תצוגת הפיתוח הזו עדיין אינה שחרור מאושר. מספר הגרסה של הדשבורד אינו מספר הגרסה של האינטגרציה. הקוד והנתונים של האינטגרציה נשארים ללא שינוי.

לתיעוד המיפוי: [ENTITY_MAPPING](docs/ENTITY_MAPPING.md). לבדיקות: [RELEASE_CHECKLIST](RELEASE_CHECKLIST.md).
