# XPENG Vehicle Card — כרטיס רכב ל־Home Assistant

**כרטיס Lovelace ייעודי לרכבי XPENG**, עם מסכים נפרדים, תצוגת רכב, טעינה, אקלים, מצב פתחים, לחץ צמיגים, מידע מתקדם ובחירת צבע חיצוני ופנימי.

> **גרסת Alpha ניסיונית וקריאה בלבד.** מדובר בפרויקט קהילתי שאינו רשמי ואינו קשור ליצרנית XPENG. אין כרגע חיבור ישיר מאומת לענן היצרן, והכרטיס אינו מפעיל פקודות רכב.

![מסך בית G6 2026](previews/g6-2026-default.png)

## מה קיים בכרטיס?

- **Overview** — הדמיית רכב, סוללה, טווח ומצב חיבור.
- **Charging** — אחוז סוללה, יעד טעינה, הספק טעינה ב־kW ואנרגיה ב־kWh רק כאשר קיימות ישויות אמיתיות עם הנתונים.
- **Climate** — תצוגת הקבינה, טמפרטורה ומצב אקלים כאשר קיימים חיישנים אמיתיים.
- **Interior & Seats** — הצגת Dark Gray או Light Gray כפי שנבחרו בעריכת הכרטיס, עם שינוי חזותי לכל הקבינה: הגה, דשבורד, דיפוני דלתות, קונסולה ומושבים קדמיים ואחוריים.
- **Controls** — תצוגת מצבי נעילה ופתחים, ללא כפתורי שליטה שאינם ממופים לפקודות מאומתות.
- **Vehicle Info / Location / Tire pressure** — ערכים רק מישויות Home Assistant קיימות.

חימום הגה, חימום/אוורור/עיסוי מושבים אינם פקדים פעילים עד לאימות יכולות ענן ישירות; עצם קיומם ברכב אינו מוכיח תמיכה ב־API.

## התקנה דרך HACS

לאחר העלאת גרסת Alpha למאגר GitHub:

1. פתח HACS → תפריט שלוש הנקודות → **Custom repositories**.
2. הזן את קישור המאגר ובחר קטגוריית **Dashboard**.
3. התקן, ודא שנוסף משאב JavaScript, ורענן את Home Assistant.
4. הוסף כרטיס **Manual** בדשבורד והדבק את ההגדרה הבאה.

```yaml
type: custom:xpeng-vehicle-card
prefix: my_xpeng
year: '2026'
model: G6
trim: core_plus_rwd
color: arctic_white
interior: dark_gray
theme: dark
```

## התקנה ידנית

1. העתק `dist/xpeng-vehicle-card.js` אל `/config/www/xpeng-vehicle-card.js`.
2. העתק את **תוכן** `dist/assets/` אל `/config/www/xpeng/` כולל תיקיות משנה.
3. הגדר משאב מסוג JavaScript module בכתובת `/local/xpeng-vehicle-card.js`.
4. הוסף להגדרת הכרטיס: `image_path: /local/xpeng`.

## תמונה מרכזית לפי קטגוריה

מסכי המיזוג והפנים מציגים איור קבינה ראשי, דלתות וצמיגים מציגים רכב מלמעלה עם חיוויים; טעינה ומיקום מציגים תמונת רכב עם שכבת מידע מתאימה. נתונים חסרים נשארים לא זמינים.

## תצוגה במסך מלא

לחצן Full screen בכותרת הכרטיס מאפשר הרחבה לתצוגת חלון מלאה וחזרה לתצוגה רגילה. הלחצן אינו שולח פקודות לרכב.

## התאמה אישית

בחירת דגם, שנתון, רמת גימור, צבע מרכב וגימור פנים מתבצעת **רק בעריכת הכרטיס ב־Home Assistant או ב־YAML**. אין לחצן התאמה אישית בתוך הדשבורד, וההגדרות נשמרות בכרטיס באופן אחיד לכל המכשירים. צבעים וזמינות גימורים תלויים בשוק, ולא כל שילוב אומת מול מפרטי היצרן השונים.

## מיפוי ונתוני רכב

הכרטיס **אינו יוצר סנסורים**. שמות הישויות לדוגמה הם מיפוי צפוי בלבד. אם חיישן חסר או אינו זמין, יוצג מקף / מצב חסר ולא ערך פיקטיבי. למידע נוסף: [עקרונות המיפוי](docs/ENTITY_MAPPING.md).

## תצוגת Cockpit חדשה ל־G6 2026

בגרסת `v0.7.0-alpha.1` נוספה אפשרות `dashboard_layout: cockpit` לפריסה ברוחב מלא: תמונת רכב מרכזית, ניווט, מסכי טעינה, מיזוג, דלתות, מושבים, **חימום הגה**, אוורור ועיסוי מושבים ומסך מלא. זהו ממשק חזותי בלבד, וכל פעולת רכב ללא API מאומת מושבתת.

ה־YAML של הדשבורד שלך נמצא בקובץ [`dashboards/xpeng-g6-cockpit.yaml`](dashboards/xpeng-g6-cockpit.yaml). ההגדרות של G6 Performance AWD 2026, צבע Arctic White, פנים Dark Gray ו־`main_nav` נשמרו. לעיצוב הישן ניתן לחזור באמצעות `dashboard_layout: classic`, או ללא שדה זה.

## צבעי רכב וריפוד — רק בעריכת הכרטיס

בגרסת `v0.7.0-alpha.1` הוסר כפתור שינוי המראה מהדשבורד. כדי לשנות את צבע הרכב או גימור הפנים: **עריכת דשבורד → עריכת כרטיס XPENG → Exterior paint / Interior finish**. הבחירה בגימור פנים משפיעה יחד על המושבים, ההגה, הדשבורד הפנימי, הקונסולה ודיפוני הדלתות. העדפות דפדפן ישנות אינן דורסות את ההגדרה.

## ממשק Studio המחודש – v0.7

המסכים החדשים מציגים את **תמונת ה־G6 המפורטת והגדולה** בכל קטגוריה. תצוגות פנים הרכב, הדלתות והצמיגים מופיעות כאיורי עזר ולא במקום התמונה. הוסר הלוגו הישן שלא נטען; כותרת ה־Markdown הכפולה הוסרה מקובץ הדשבורד המומלץ. ה־navbar הקיים `main_nav` נשמר והוגדל המרווח בתחתית המסך כדי למנוע חפיפה.

גרסת הפריסה הזו כוללת צילומי מסך אמיתיים מבדיקת Chromium גם למסך מחשב וגם לאייפון — ניתן לראות אותם בתוך קובצי השחרור ב־GitHub. תמונות ההדמיה המוקדמות אינן תיעוד של הקוד המקורי. שאר הפעולות שמצריכות הרשאות XPENG מושבתות עד לאימות API. צבעים וריפוד נקבעים רק דרך עריכת הכרטיס.


## בנייה מחדש מלאה — תצוגת ניסיון 0.9 (טרם שוחררה)

כרטיס XPENG אחד עם רכב גדול, ארבע פעולות מהירות, ותפריטי Controls / Climate / Location / Charging שמחליפים את המסך הראשי. קיימים מסכי נעילה/דלתות וצמיגים, מיזוג עם חימום הגה ומושבים, טעינה ומצב מיקום. הבחירה בצבע ובגימור פנים נעשית רק בעריכת הכרטיס; `main_nav` נשאר בדשבורד. כל פקודה שטרם אומתה מול XPENG מושבתת. תמונות בדיקה אמיתיות נוצרות על ידי Chromium לפני כל שחרור.
