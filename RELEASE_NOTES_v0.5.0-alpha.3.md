# XPENG Vehicle Card v0.5.0-alpha.3 — public alpha candidate

Initial community preview of an independent Lovelace vehicle dashboard for XPENG owners.

### Highlights

- Separated vehicle, charging, climate, interior, controls and data pages.
- G6 2026 facelift concept visual, year/model/trim/paint selector.
- Dark Gray and Light Gray cabin finish selection updates steering wheel, dashboard, centre console, door inserts and front/rear seats together.
- No invented sensors, undocumented API calls or simulated live values.
- Repacked HACS `dist/` includes the plugin JS and asset library.
- Automated syntax, browser and packaging tests added.
- English and Hebrew documentation included.

### Important limitations

- Read-only. No vehicle remote commands or verified direct manufacturer API.
- Vehicle illustrations for other models and all market variants are illustrative.
- Real Home Assistant / HACS installation and CI must pass before stable release.
- This is an unofficial community project without manufacturer affiliation.
