# XPENG Vehicle Card v1.0.5-beta.3 — G6 communication and telemetry preview

Optional HACS prerelease. Stable v1.0.4 remains unchanged.

## Existing beta improvements
- Seven read-only climate status tiles.
- Shared fan-speed bar for desktop and mobile.
- Charging Current (A) and Voltage (V) in the existing charging view.

## Wi-Fi icon: two independent statuses
- **Connection** shows the existing MQTT transport sensor when mapped, otherwise the integration connection sensor.
- **Vehicle data** separately shows Recent, Old or Unknown using the mapped vehicle-update timestamp, with an age and the last-update time.
- **Recent** means a valid timestamp within two hours; **Old** means more than two hours. Unknown/missing timestamps are not treated as fresh. Sleeping/parked cars can legitimately have old timestamps.
- The existing Wi-Fi button opens the details popover; the icon uses amber when connected with old data, neutral when the timestamp is unknown, and the existing disconnected/error indications when appropriate.
- MQTT connectivity does not prove that XPENG supplied new data. Home Assistant entity last_updated is not used as evidence of a vehicle refresh.

## Installation
HACS → XPENG Vehicle Card → Redownload → Need a different version? → v1.0.5-beta.3.

This is read-only UI status; it does not alter polling, commands, vehicle wake-up or the integration's stale-location behavior. Verify the actual timestamp and connection sensor mappings in your Home Assistant instance.
