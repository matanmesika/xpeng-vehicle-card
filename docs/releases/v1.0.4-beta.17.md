# XPENG Vehicle Card v1.0.4-beta.17 — Overlay-only final visual polish

**Opt-in prerelease. Do not merge into stable main without owner confirmation.**

## Approved Beta 16 baseline closed
Beta 16 remains available as a rollback point. All Beta 16 requirements are considered delivered in the opt-in preview; new visual requests belong only to this Beta 17 branch.

## New requests and changes
- Shrink desktop Climate modal without changing seat, fan, steering, zone, or any HA command handlers.
- Restore the larger desktop More options launcher; keep diagnostics scroll intact.
- Opening a popup no longer drops the `xp-home-navigation` scene class, thus preserves exactly the same home background/photo, vehicle composition, and status layout while the popup is present. No zoom or scene scale transition.
- Remove unwanted native hover tooltip box from all seven Home shortcuts; maintain keyboard focus indication only via `:focus-visible`.
- Enlarge seven round desktop Home buttons themselves (68px rings), not just their official MDI pictograms; preserve compact iPhone sizes.
- Replace ambiguous custom tailgate/arrow composite with a single real official MDI rear-vehicle icon. Opening/closing captions remain state-aware.
- Clean heading hierarchy and remove duplicate XPENG in the card's own header/title.
- Native Home Assistant Location: real device_tracker coordinates only, native `label_mode: icon` marker. Supply the map-only view with `mdi:car-back`; never mutate the actual HA entity, never synthesize coordinates. Recenter with the supported `ha-map.setView` method so MapLibre and Leaflet work. Do not force camera during subsequent HA state refreshes or manual map pan.
