# XPENG Vehicle Card v1.0.6 — Stable

Stable HACS release following v1.0.5. The owner approved the revised charging layout from v1.0.6-beta.2 and requested publication with updated integration-description screenshots.

## Charging view
- **Electrical metrics grouped together** in one row: Charging power (kW), Current (A) and Voltage (V).
- **Charging session metrics** in the next row: Time remaining and Charge limit.
- Correct electrical labels/icons: **A** for Current, **V** for Voltage; no speedometer used for electrical measurements.
- Missing or invalid Current/Voltage display **0.0 A** / **0.0 V** as requested. These are visual placeholders, not measured zeroes.
- Retains battery SOC, range, station/car/cable artwork and three charging controls. The mobile layout avoids covering the car.

## Retained from v1.0.5
- Seven read-only Climate status tiles and shared Climate fan styling.
- Wi-Fi/integration connection vs. vehicle data freshness display.
- No change to XPENG polling, GPS updates, permissions or vehicle commands.

## Installation
HACS → XPENG Vehicle Card → Update (or Redownload) → **v1.0.6**. Refresh Home Assistant's frontend and clear its cached JS bundle if necessary.

## Validation and limitations
The release workflow verifies source/dist parity, regression tests, real Chromium desktop/iPhone responsive geometry and curated screenshot PNGs before publishing. Browser tests use simulated vehicle states and do not establish live-car execution or iPhone Safari behavior.
