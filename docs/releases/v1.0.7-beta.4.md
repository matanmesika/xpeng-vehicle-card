# XPENG Vehicle Card v1.0.7-beta.4 — observed Xpengtk entity aliases

Opt-in HACS prerelease based on v1.0.7-beta.3.

## What's new
- Adds automatic aliases for the Xpengtk entity IDs observed in the current Home Assistant instance: `number.*_charge_limit`, `binary_sensor.*_climate`, `lock.*_door_lock`, and `cover.*_trunk`.
- Normalizes open/closed and locked/unlocked states for boolean dashboard fields.
- Keeps the complete manual mapping editor for all dashboard telemetry fields and retains rename-resilient registry matching.

## Compatibility
- Existing automatic and manual mappings remain supported.
- Entities that are not present in the Home Assistant state registry remain blank; the card does not substitute unrelated values such as last-charge energy for current-session energy.
- Actual vehicle controls still depend on Xpengtk capability and command-policy checks.

## Install
In HACS, open XPENG Vehicle Card → **Redownload** → **Need a different version?** and select **v1.0.7-beta.4**. Refresh the Home Assistant frontend after installation.
