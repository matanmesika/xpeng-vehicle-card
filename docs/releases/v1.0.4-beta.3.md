# XPENG Vehicle Card v1.0.4-beta.3 — תיקוני Home Assistant במובייל ומפה

**גרסת בטא למבחן חי ברכב.** ממשיכה את beta.2 בלי להחליף את v1.0.3 היציבה ובלי למזג את PR #44.

## תיקונים בבטא זו
- מסך תחזוקה שנפתח דרך גלגל השיניים משתמש כעת בפריסה הראשית של התחזוקה, עם תמונת הרכב מלמעלה וארבעה צמיגים — במקום להיות מוטמע בתוך מסך "אפשרויות נוספות". חזרה מחזירה לגלגל השיניים.
- אבחון ישויות: אזור הגלילה הפנימי הוסר; הגלילה מתבצעת בתוך חלון אחד במובייל, בלי מחוות מתנגשות.
- בגלילה בטלפון נשמרים מיקום חלון המשנה ומיקום אבחון הישויות בעת שינוי מצב חיישנים; מעברי חזרה מחלון פנימי שומרים על ההיסטוריה.
- מפת Home Assistant נבנית פעם אחת עבור ישות ה־device_tracker של הרכב, נשארת מחוברת גם כשהנתונים מתעדכנים, ומקבלת hass מעודכן בלי להסיר את המפה ולרצד. **האריחים האמיתיים מחייבים בדיקה ב־HA המותקן.**
- יישור סמל הקישוריות בכותרת של המסך במחשב (בטלפון נשמר המיקום הקודם).
- אייקוני חלונות ותא מטען הוחלפו לסמלי MDI מקוריים: window-open, window-open-variant, car-hatchback.
- שנת הדגם מוצגת עם תווית מקור: המאפיין `model_year` מתוך `sensor.vehicle_identity` אם האינטגרציה חושפת אותו; אחרת שנת הדגם שנבחרה בהגדרות כרטיס (ברירת מחדל 2026), שאינה עוברת אימות VIN אוטומטי.
- ללא שינוי לפקודות הטעינה, החימום, המושבים או הישות שנבחרה לרכב.

## הוראות התקנה ב־HACS
HACS → XPENG Vehicle Card → ⋮ → Redownload → Need a different version? → `v1.0.4-beta.3` → רענון Home Assistant במחשב ובאייפון. אם גרסאות ניסוי אינן מוצגות יש להפעיל pre-releases עבור המאגר.

## מה עדיין חייב בדיקת משתמש
- גלילה באייפון פיזי עם נתונים משתנים
- גלילת אבחון מול כמות הישויות המלאה של הרכב
- מפת Home Assistant אמיתית (לא ה־placeholder של Playwright), כולל מצב GPS וריצוד
- התאמת צילומי הרכב לצבע/שנת הדגם שנבחרו, ודיוק חיישנים
- נסיעת רכב ופקודות פיזיות אינן כלולות בבדיקות CI; נהגו בבטיחות.
