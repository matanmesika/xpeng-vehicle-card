# XPENG Vehicle Card v1.0.7-beta.2 — Xpengtk entity mapping

Opt-in HACS prerelease based on v1.0.7-beta.1. This beta adds rename-resilient automatic mapping for Xpengtk entities and keeps the capability-guarded G6 climate controls.

## What's new
- Discovers all entity domains attached to the selected Xpengtk vehicle from Home Assistant's Entity Registry using the stable Xpengtk unique ID and Home Assistant device ID.
- Resolves current entity IDs after a user renames an entity. Refreshes registry mapping when a previously present entity ID disappears during a rename or integration reload.
- Tries canonical Xpengtk keys before known aliases. Unknown keys are never guessed into an action; actual entities remain visible in Entity Diagnostics.
- Selects a sole Xpengtk vehicle automatically. With multiple vehicles, requires `xpeng_device_id` or an unambiguous prefix and never mixes cars.
- Adds an official-source catalogue of all 76 current Xpengtk sensor keys plus other entity platforms.
- Retains the seven climate On/Off buttons only when Xpengtk explicitly reports a known state and `control_allowed: true`.

## Compatibility and limitations
- Entity Registry access uses Home Assistant's authenticated WebSocket command. If Home Assistant rejects that read, the card falls back to known entity prefixes; renamed IDs may then require registry permissions or an explicit mapping.
- Only stable-key changes with a known alias can be followed automatically. Unrecognized upstream keys are not inferred from a friendly name.
- Climate controls still require Xpengtk 0.6.28+ capability and command-policy support. Actual physical operation has not been verified on the owner's G6; test one function at a time while parked.
- Existing stable v1.0.6 and v1.0.7-beta.1 remain available for rollback.

## Validation
The release workflow checks generated bundle parity, HACS metadata, the full Node regression suite, and Chromium desktop/mobile captures before publishing this opt-in prerelease.

## Install
In HACS, open XPENG Vehicle Card → **Redownload** → **Need a different version?** and select **v1.0.7-beta.2**. Refresh the Home Assistant frontend after installation. To roll back, select **v1.0.7-beta.1** or stable **v1.0.6**.
