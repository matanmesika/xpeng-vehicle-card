# XPENG Vehicle Card v1.0.4-beta.20 — post-Beta 19 owner preview

**Status:** Optional prerelease for testing in a real Home Assistant installation. This is **not** a stable release and must not be merged into `main` without separate owner approval.

## Corrections since Beta 19

- Align the Back arrow in desktop and iPhone dialogs; preserve navigation history and backdrop-to-Home behavior.
- Display Settings and Wi-Fi in their approved desktop positions, while narrow phone dialogs correctly cover the header controls.
- Recenter the native Home Assistant location map whenever the Location page opens, using the actual device tracker and zoom 16; do not manufacture GPS data or repeatedly override user panning.
- Restore contextual help in Software Updates. Show only integration-supported XOS/OTA status and automatic-update controls. Do not invent a manual Check for Updates action.
- Use **English-only** card UI, editor labels, status/help and errors even when Home Assistant uses a Hebrew locale.
- On phones, show the tyre symbol above each tyre's label and measured pressure.
- Preserve the approved G6 night lakeside backdrop, vehicle photos, charging pedestal/green cable, climate/seat commands, and seven quick actions. No new unsupported XPENG commands.

## Code and test integrity

- Styling is maintained in `src/design/xpeng-vehicle-card.css`; functional runtime in `src/core/xpeng-vehicle-card.runtime.js`. The self-contained source and HACS distribution bundles must match byte-for-byte.
- The protected vehicle-control regression test permits approved *display-copy* translations only. Entity suffixes, permission checks, command dispatch and toggle semantics remain guarded; existing owner-approved Horn/Flash direct-tap behavior remains.
- Independent QA on the candidate base commit `2317624326c478bca0e728581a00e0c7175eb852` passed all three parallel lanes: vehicle/sensor regression, English/design/navigation regression, and 14 genuine Chromium desktop/iPhone/Sections captures.
- Frontend, HACS and artwork verification also passed on the same candidate.
- The publication workflow reruns QA and produces fresh captures before publishing. **Never publish on a failing verification step.**

## Install or roll back through HACS

Go to **HACS → XPENG Vehicle Card → menu → Redownload → Need a different version?** and explicitly choose `v1.0.4-beta.20`. Restart/reload Home Assistant as needed, and force-refresh the browser/iPhone app cache to load the changed JavaScript. If anything regresses, select `v1.0.4-beta.19` the same way.

## Required real-device acceptance

Automated browser captures use **simulated Xpengtk entity values** and a **map placeholder**; they cannot establish actual GPS map behavior, real commands, or iPhone Safari compatibility. Check the map on every opening, the Back arrow and modal overlays, software-update help, tyre symbols, charging transitions, HVAC and supported vehicle actions. Report regressions on PR #57.
