# XPENG Vehicle Card v1.0.4-beta.16 — desktop final UI polish

**Opt-in prerelease candidate; no stable main merge.** Changes build on the owner-tested Beta 15 design.

## Owner feedback applied

- **Main desktop action dock:** official MDI icons enlarged to 30px; iPhone-sized card untouched.
- **Home battery:** enlarged sensor-driven battery indicator; removed its decorative green circle on desktop and mobile. Charging/SOC status continues to use live Home Assistant states.
- **More options:** seven official pictograms become 30px inside 62px glass circles on desktop; iPhone glyph sizes remain unchanged.
- **Adaptive modal geometry:** narrow and center the More-options launcher and small option dialogs; preserve a large scrolling diagnostics window, two-column desktop TPMS/service and the approved Climate controls.
- **Location:** keep native Home Assistant map and live vehicle entity; after the first map mount, attempt a one-time Leaflet size correction and camera center on the actual tracker latitude/longitude with zoom 16. If GPS or native map internals are unavailable, fall back to existing HA map logic without inventing coordinates or repeatedly overriding user panning.
- **Layout:** match window widths to the visible controls and preserve mobile/Sections scroll behavior.
