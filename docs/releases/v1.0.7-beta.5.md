# XPENG Vehicle Card v1.0.7-beta.5 — cover state and fan telemetry

Opt-in HACS prerelease based on v1.0.7-beta.4.

## What's new
- Reads open/closed status from Xpengtk cover entities for trunk, windows, and charge-port flap when their binary sensor or charge-port enum is not available.
- Adds the observed `sensor.*_hvac_fan_speed` to automatic and manual telemetry mapping.
- Shows fan speed as read-only when Xpengtk exposes a sensor but no controllable `number` entity. A read-only sensor is never presented as a control.

## Compatibility
- Existing automatic registry matching and manual entity overrides remain supported.
- No Home Assistant entities need to be renamed or replaced.
- Actions remain available only when the corresponding control entity and permission are present.

## Install
In HACS, open XPENG Vehicle Card → **Redownload** → **Need a different version?** and select **v1.0.7-beta.5**. Refresh the Home Assistant frontend after installation.
