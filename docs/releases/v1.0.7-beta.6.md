# v1.0.7-beta.6

Opt-in beta for XPENG G6 dashboards using Xpeng Toolkit.

## Changes

- Support both unified Xpeng Toolkit covers and separate per-action sensors/buttons for the trunk, windows, and charge port.
- Resolve renamed cover entities through Home Assistant's entity registry, with stable Xpeng Toolkit unique-ID aliases.
- Display the AC current limit separately from the vehicle battery charge limit.
- Tighten and reposition the mobile charging information card so it stays clear of the vehicle image.
- Preserve the live green charging cable, artwork, sensor-driven charging scene, and responsive desktop/mobile layout.

## Install

In HACS, open **XPENG Vehicle Card → Redownload → Need a different version?** and choose **v1.0.7-beta.6**. Reload the Home Assistant frontend after installing. This is an opt-in prerelease; v1.0.6 remains the stable release.

## Compatibility

Requires a separately configured Xpeng Toolkit Home Assistant integration. Controls appear only when the relevant entities are available. The charging display uses the integration's reported telemetry and does not verify commands at the vehicle.
