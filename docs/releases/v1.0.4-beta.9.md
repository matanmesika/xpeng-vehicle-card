# XPENG Vehicle Card v1.0.4-beta.9 — Screen-fit, GPS map and diagnostics layout

**Beta / pre-release** — retains all Beta 8 fixes, authentic vehicle images, original night-lake composition, automatic charging, Xpengtk controls, bilingual Hebrew/English, and 7 home/charging shortcuts.

## New in Beta 9

- **Location:** the native Home Assistant map fills the *remaining* subpage height (rather than reserving a fixed 350–520px minimum), and its 3 actions stay visible underneath the map without scrolling the whole overlay.
- **Responsive screens:** modal/header/page content is arranged inside the card's own dimensions; on narrow cards the scene height adapts to the viewport using `dvh` with a sensible floor. The layout responds to the **card's container width**, so Home Assistant Sections on a desktop behaves like the same-width iPhone card. English and Hebrew receive the same fit rules.
- **Wi-Fi:** the MDI glyph uses geometric centering inside its real 42px/38px button, without the earlier manual vertical offset; the communication/cog spacing remains 14px desktop, 8px narrow.
- **Diagnostics:** the entire Xpengtk entity list is retained, but shown inside a compact, independently scrollable panel (up to 292px desktop / 230px narrow). Both the availability summary and the explanatory note stay visible outside the list. All sensor and command identifiers remain read-only and unchanged.
- **Sections card contract:** `getGridOptions()` returns `{columns:12,min_columns:12,rows:'auto'}`, following the official HA custom-card sizing API. Fixed section-row heights are not forced on a graphical vehicle card; allow the dashboard to determine the height from content.

## Home Assistant official references

- [Custom card sizing and `getGridOptions()`](https://contributors.home-assistant.io/frontend/custom-ui/card/)
- [Design principles for Sections and 12-column card grid](https://contributors.home-assistant.io/design/dashboards/)
- [Resize cards in Sections → Layout → Full width card](https://www.home-assistant.io/dashboards/cards/)

For best results, use one card per full-width Section or a Panel view. Keep the Home Assistant mobile application and frontend current. The card automatically adapts to available width; no dedicated phone dashboard, zoom or second YAML card is required.

## Tests and remaining verification

Automated tests use a Home Assistant/Xpengtk simulator and a Chromium browser at desktop (1440px), iPhone (390/320px), and narrow Sections (420px) widths. They verify that the map and modal are within the card, Wi-Fi icon geometrically centered, the diagnostic note visible and scrolling restricted to the sensor list; plus the maintained stress/regression suites, HACS/artwork validation and 12 original screenshots.

**Limitations:** the mock HA map has no real Leaflet tiles. Content fit is checked at test sizes; unusually short screens, browser-level text enlargement or unsupported CSS may require reflow and a fallback. Always confirm real iPhone Safari, home dashboard Sections and real native map before approving a stable release.

## Install and rollback

HACS → XPENG Vehicle Card → ⋮ → Redownload → Need a different version? → `v1.0.4-beta.9`. The stable `v1.0.3` and prior `v1.0.4-beta.8` remain selectable. No merge to `main` occurs as part of this Beta.
