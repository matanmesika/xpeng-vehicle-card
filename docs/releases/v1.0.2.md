# XPENG Vehicle Card v1.0.2 — Appearance and dashboard gallery fixes

A maintenance release of the XPENG **frontend card**. The XPENG vehicle
integration/backend and sensor API have not been changed.

## Fixes
- Group shared model years by their visual generation/facelift in the card editor
  for all 15 supported models. The G6 now offers `2023–2025 · Original G6`
  and `2026 · Facelift`, while older individual-year configurations continue
  to resolve to the same generation.
- Preserve year-specific paint choices: P7i 2024 keeps a specific year picker
  because its available colours differ from 2023 and 2025.
- Rename 2026 Israeli-market G6 trim labels to exactly Core RWD,
  Core+ RWD, Core Performance AWD and Black Edition, without combining names
  from the previous model generation.
- Include **real browser captures** of the card's Vehicle Status, Charging
  and Tire Pressure screens in the README, captured with explicit synthetic
  demo sensor values. These are dashboard screenshots, not car cutout layers.
- Add automated checks for grouped generations, trim labels, year-specific
  palettes and the three documented dashboard PNG files.

## Installation
Update the XPENG Vehicle Card custom repository in HACS to v1.0.2, then
reload the browser's cached Home Assistant frontend resources.
If manually installing, follow the [HACS instructions](../../README.md).

## Non-changes
This update does **not** assert completion of missing model artwork:
pending front/charging/top view slots remain openly tracked in
[docs/FULL_MODEL_COVERAGE.md](../FULL_MODEL_COVERAGE.md).
The approved lakeside background is unchanged.
