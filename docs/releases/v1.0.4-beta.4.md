# v1.0.4-beta.4 — MDI icons and modern Back navigation

Historical prerelease, not merged to main. Added native Home Assistant Material Design Icons for actions, status, battery and charge station, with a unified icon registry. Preserved all integration commands, night background, original vehicle artwork and charging display. At the time the right-pointing RTL Back arrow was intentional; the current English-only card uses a left-pointing Back arrow.

QA evidence: [Frontend](https://github.com/matanmesika/xpeng-vehicle-card/actions/runs/39115344517), [HACS](https://github.com/matanmesika/xpeng-vehicle-card/actions/runs/39115344457), [artwork](https://github.com/matanmesika/xpeng-vehicle-card/actions/runs/39115344459), [Chromium](https://github.com/matanmesika/xpeng-vehicle-card/actions/runs/39115341120).

Real iPhone Safari, live Xpengtk commands and native map centering require owner testing. For current acceptance see [final stabilization](../G6_FINAL_STABILIZATION.md).
