# v1.0.4-beta.6 — Automotive windows and trunk icons

Historical opt-in prerelease incorporating earlier mobile fixes. Changed the windows icon to the native MDI `mdi:car-door` instead of a house-window illustration, and updated the tailgate icon to the appropriate rear-car symbol available at that time. No sensor mapping, vehicle command or permission behavior changed. Preserved the owner's vehicle artwork, lake background, mobile scroll and repeated-action safeguards.

Original Chromium/HACS checks used simulated entities, not a real connected G6. The current card has an improved approved raised-hatch side-profile icon. [Final acceptance](../G6_FINAL_STABILIZATION.md).
