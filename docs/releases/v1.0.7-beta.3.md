# XPENG Vehicle Card v1.0.7-beta.3 — complete manual sensor mapping

Opt-in HACS prerelease based on v1.0.7-beta.2.

## What's new
- Manual sensor mapping now includes every telemetry field read by the dashboard, rather than only the original 15 fields.
- The editor groups mappings into vehicle, battery, range, charging, vehicle status, climate, and tires.
- The manual field list is generated from the card's telemetry keys, keeping it aligned as dashboard fields change.
- Each manually assigned entity remains an explicit override. Leave a field blank to use automatic XPENG registry/prefix matching for that field.
- Automatic mode remains available and continues to follow renamed entity IDs through Home Assistant's Entity Registry where permitted.

## Compatibility
- Existing manual mappings remain valid; the editor now exposes additional dashboard fields.
- Unknown Xpengtk keys are not guessed from friendly names.
- Existing stable v1.0.6, v1.0.7-beta.1, and v1.0.7-beta.2 remain available for rollback.

## Install
In HACS, open XPENG Vehicle Card → **Redownload** → **Need a different version?** and select **v1.0.7-beta.3**. Refresh the Home Assistant frontend after installation.
