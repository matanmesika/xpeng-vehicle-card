# XPENG Vehicle Card v1.0.4-beta.14 — G6 owner-preview candidate

**Status:** Candidate. Publish only after automated checks pass. This does not approve a stable `main` merge.

## Beta 13 → Beta 14: owner-requested fixes

This release branch was forked from the V3 design head on 19 October 2026, including all 11 commits following the `v1.0.4-beta.13` tag. Beta 13 is accepted as the visual baseline for this comparison.

- **Maintenance / TPMS:** four tire pressures around the original overhead G6 artwork. No odometer, VIN or service/identity widgets on this page. Tire units come from card settings. Tire temperature and air life only appear if the mapped tire entities supply their attributes; no invented values.
- **HVAC:** refined center controls for target temperature, AUTO/power, live fan range, and supported optional climate features. Cabin photo, front heating/cooling hotspots, rear heat and steering wheel hotspot retain direct seat/wheel-level cycling with real mapped Home Assistant entities. Do not assume ten fan levels if the entity reports a different range.
- **Charging:** revised charging pedestal appearance without replacing the original car artwork, route of the green active cable, automatic charging scene selection, charge-limit or schedule commands.
- **Owner imagery:** approved night lakeside background, two cabin colours selected in the card editor, original vehicle photographs and navigation are preserved.
- **Responsive:** same card on desktop / Home Assistant Sections / iPhone. Seven Home shortcuts, seven Custom Functions, help panels, tire readings, diagnostics scrolling and map actions remain in place.
- **Real browser previews:** 14 saved Playwright Chromium captures in `docs/screenshots/`, including desktop and mobile Home, Charging, Climate, Maintenance, Map, Functions, plus diagnostics and charge controls.

## Automated release gates

1. Syntax, generated JS equivalence, HACS schema and full source build check.
2. G6 regression and design guardian test suites (including charging, TPMS-only, climate hotspots, navigation and responsive layout).
3. Live Chromium/Playwright desktop, mobile and narrow Sections tests.
4. Validation of all 14 new PNG captures and packaging of preview screenshots.
5. Only if every earlier step passes: publish a **pre-release** tag `v1.0.4-beta.14` from the tested branch commit.

A red, cancelled, pending or **action_required** GitHub Actions run is **not** a passing result. Do not assert release success before seeing the actual GitHub release tag and checks.

## Owner tests required before stable merge

Install the opt-in beta from HACS after publication. On a real Home Assistant instance and safely parked vehicle, check the dashboard with real sensor states, charging transition and stop/start context, climate zones, window/lock/trunk/port buttons, TPMS, GPS/native map, iPhone scrolling and all supported extras. Browser screenshots use demonstration entities; native map tiles and physical vehicle command delivery cannot be certified by Chromium.
