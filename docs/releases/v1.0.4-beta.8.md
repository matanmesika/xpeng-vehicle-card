# XPENG Vehicle Card v1.0.4-beta.8 — English support and faster first Location open

**Pre-release for live Home Assistant testing**, including all beta.1–beta.7 fixes. The stable `v1.0.3` remains unchanged; PR #44 stays Draft and is not merged.

## What's new

- **Hebrew and English user interfaces:** the card automatically follows Home Assistant's current user interface language. The same single card supports Hebrew (RTL) and English (LTR), with translations for the seven main actions, charging, climate and seat controls, windows/tailgate, tire pressure, maintenance, extras/diagnostics, GPS, status messages, button titles, accessibility labels and configuration editor. English Back arrows point left; Hebrew Back arrows point right. User-selected options, real entity state values and automation commands remain unchanged.
- **Faster first map open:** Home Assistant's official `loadCardHelpers()` bundle is warmed once as soon as the card has Home Assistant state, rather than waiting until the first Location tap. A shared promise prevents multiple fetches when the card rerenders or multiple instances coexist. The actual native HA map is instantiated only when Location is opened and stays mounted across GPS/sensor updates. No remote vehicle query or vehicle command occurs due to preloading.
- **Existing behavior preserved:** no extra charging navigation button, seven dock actions in both scenes, original car artwork and cabin images, nighttime lake background, the green charging cable, official car-door/car-back MDI icons, Wi-Fi alignment, uniform action icon colors, direct-command confirmation and stable mobile scrolling.

## Verification before publishing

The release is published only after JavaScript/unit regressions, all Xpengtk sensor simulations, frontend and HACS validation, official MDI icon verification, artwork provenance, Chromium/Playwright across desktop/mobile/HA Sections, the 12 curated screenshots, and language plus map-preload regression checks pass.

**Limitations:** this reduces JavaScript initialization latency but cannot guarantee immediate downloading of map tiles on slow external networks. CI does not connect to the owner's physical iPhone, live Home Assistant, Xpengtk vehicle or actual tile servers. Visual confirmation in the user's installation is still required.

## Install

HACS → XPENG Vehicle Card → ⋮ → Redownload → Need a different version? → `v1.0.4-beta.8`. Enable pre-releases if necessary; refresh the Home Assistant web view/app after installing.

## Rollback

In the same HACS Redownload menu, select `v1.0.4-beta.7` or stable `v1.0.3` and refresh the browser/app.
