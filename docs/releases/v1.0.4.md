# XPENG Vehicle Card v1.0.4 — Stable

A community-developed Home Assistant Lovelace dashboard frontend, visually reviewed for XPENG G6. This release does not alter the independently installed Xpengtk integration.

## Highlights
- **One shared Charging component for desktop and phone.** The same data panel and controls render on desktop, iPhone, and narrow Sections cards; only dimensions scale automatically.
- **Charging controls redesigned.** Three real Home Assistant Material Design Icons, correctly centered in individual glass rings with centered text. Charge limit, charging schedule, and supported stop-charging commands retain their existing state/permission logic.
- **Owner-approved G6 charging scene.** Original night-lakeside backdrop, car and cabin art, photo XPENG charging pedestal, thin green conditional charging cable and visual layering retained.
- **Consistent dashboard.** Battery, range, power, time remaining, charge target, climate/seat/wheel comfort, four-tire TPMS, supported vehicle actions, diagnostics, native Home Assistant location and seven quick actions.
- **English/HACS release cleanup.** Current README and HACS descriptions, consolidated 14 real Chromium screenshots, removed obsolete prerelease workflows and duplicate capture sets while keeping all needed artwork/mapping data.

## Validation
The publishing workflow verifies package syntax and bundle parity, HACS metadata, current automated regression tests, vehicle artwork/provenance and browser captures on wide desktop, 390px/320px phone and narrow 420px Sections sizes.

**Important:** screenshots are real Chromium renders using *simulated Xpengtk sensor states*. They are not real iPhone Safari screenshots, a guarantee of working commands or proof of GPS accuracy. Other XPENG model images remain partially incomplete.

## Install / update
1. Configure the separate Xpengtk Home Assistant integration.
2. In HACS, add `https://github.com/matanmesika/xpeng-vehicle-card` as a custom **Dashboard** repository if needed.
3. Download stable `v1.0.4` and refresh the frontend/browser cache.
4. Add `custom:xpeng-vehicle-card` to a dashboard and configure the correct model/year/paint/interior and actual entity mappings.
5. Keep access functions disabled unless permissions and physical behavior have been safely verified.

The previous stable `v1.0.3` and historical betas remain as rollback releases. This project is not affiliated with XPENG.
