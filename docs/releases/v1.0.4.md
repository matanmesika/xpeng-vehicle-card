# XPENG Vehicle Card v1.0.4 — Stable Release Candidate (DRAFT)

**Not published.** This is review copy only. The published stable tag is currently `v1.0.3`. The last public prerelease is `v1.0.4-beta.21`. No stable tag should be created until the owner approves live Home Assistant screenshots and vehicle tests.

## Highlights

- Modern, single-card XPENG dashboard with the original night-lakeside background and responsive desktop, iPhone and Home Assistant Sections layouts.
- Automatic charging scene with live battery/charge values, improved photographic XPENG station and thin green cable; final station position follows the owner's annotated front-right placement.
- Mobile charging information compacted above vehicle art without obscuring the car, station or available actions.
- Charging station is behind the vehicle image; the dynamic charging cable renders above the vehicle, while the information panel stays readable.
- Responsive Climate and cabin controls using supported Xpengtk entity mappings, including supported seat and steering-wheel comfort functions.
- Four-position TPMS, native vehicle location and supported vehicle actions with status/permission safeguards.
- Corrected Back navigation, Climate hover, More Options icon hover, English-only interface, Software Updates explanation and map re-centering when opened.
- Retained supported entity aliases, status-aware labels and duplicate-command safeguards.

## Integration and availability

This is **a Lovelace frontend**, not the Xpengtk backend. It does not authenticate to XPENG, create sensors, guarantee that a sent command executed, or enable functions not exposed by Home Assistant. The G6 is the primary reviewed model. Vehicle photo coverage is incomplete for some paints/models; model artwork and third-party licensing remain separately tracked.

## Install

Add `https://github.com/matanmesika/xpeng-vehicle-card` as a HACS custom **Dashboard** repository and install `v1.0.4` only **after it has been officially published**. Before approval, select the existing `v1.0.4-beta.21` for preview, or test a candidate JavaScript bundle from the review branch. Clear your frontend cache after changing versions.
