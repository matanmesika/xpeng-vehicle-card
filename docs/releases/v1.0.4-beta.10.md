# XPENG Vehicle Card v1.0.4-beta.10 — Owner screenshot fixes

**Beta / prerelease for Home Assistant testing, not approved as a stable update.** Builds on the G6 beta.9 layout, automatic charging, real Xpengtk entity mapping, bilingual Hebrew/English and original night-lakeside / vehicle / cabin artwork.

## What's included in Beta 10

- **Tailgate:** use native HA Material Design rear-car icon (`mdi:car-back`); English open action label is exactly **Open Trunk**.
- **Maintenance / TPMS:** separate tire illustration and its four wheel-positioned pressure readings from service/identity cards below; isolate overlapping layers and add space before the detail grid.
- **Entity diagnostics:** keep exactly one entity per visual row and its value alongside; long identifiers stay on one line and can be inspected by horizontal scrolling with touch/keyboard inside that line. The list remains a contained scroller.
- **Climate on narrow cards:** reserve horizontal space for both +/- buttons and target temperature without hiding the increase control; preserve the owner-provided interior images and seat/steering hotspots.
- **Top bar clearance:** reduce responsive scene height to leave additional room for native Home Assistant header/navigation on phones and narrower card containers, without creating a separate phone dashboard.
- **Documentation and testing:** restore HACS-required “Sensor mapping” documentation, add owner-specific regression assertions, keep source and HACS `dist` identical, and retain all existing G6 beta.9 functionality.

## Inherited fixes from earlier review branch

Dynamic true-MDI SOC/battery and active-charging icon, English **Update details**, no routine success toast after `hass.callService`, transparent seat/wheel touch controls bound to existing integration entities, direct state-guarded trunk/window/door/charge-flap actions, seven shortcuts on Home and automatic charging scene.

## Limitations / real-vehicle verification

- **Black Edition is not fully ready:** dark interior appearance is enabled but dedicated approved all-black body / interior source photographs are not available. Do not substitute another paint as authentic Black Edition.
- Simulated Chromium tests do **not** prove physical G6 commands are executed. A fulfilled `hass.callService` only indicates acceptance by Home Assistant; inspect live command feedback, actual entity state and parked-car behavior.
- Native HA GPS map tiles and iPhone Safari / HA bottom navigation should be checked in the actual Home Assistant app. Demo captures use simulated Xpengtk states and mock map tiles.
- If the visual layout remains clipped on any device, send screenshots with screen width and HA version; avoid including VIN, GPS coordinates or tokens.

## Installation

Home Assistant → HACS → XPENG Vehicle Card → ⋮ → **Redownload** → **Need a different version?** → `v1.0.4-beta.10`.

Refresh the Home Assistant frontend/app after installing. Existing stable release `v1.0.3` and the previous `v1.0.4-beta.9` are retained as rollback options.

This prerelease does **not** merge `main`, update the Xpengtk backend or grant new vehicle-control permissions. Owner validation is expected **after** installing this beta, before any stable merge.
