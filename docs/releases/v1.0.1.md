# XPENG Vehicle Card v1.0.1

Includes all code and documentation merged into main since the previous published release, including direct/manual HACS installation instructions, updated visual documentation, and automated regression checks.

This is the **frontend dashboard card**, not a vehicle API integration. Full real dashboard screenshots have **not** been committed. Vehicle art remains illustrative where original imagery is unavailable; some model/year/paint combinations lack final images. This release does not claim live vehicle connectivity.

Install through HACS as a custom **Dashboard** repository: https://github.com/matanmesika/xpeng-vehicle-card . Confirm the version shown by HACS matches `v1.0.1`.
