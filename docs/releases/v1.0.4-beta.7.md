# v1.0.4-beta.7 — Connectivity header alignment and icon consistency

Historical opt-in prerelease based on Beta 6. Added a 14px desktop gap between Settings and Wi-Fi, adjusted the Wi-Fi glyph vertically without changing its hit target, and made the seven shortcuts use consistent neutral icon color. Preserved meaningful live colors for charge, battery, connection and disabled status. No vehicle service dispatch, sensor or permission changes.

At the time the release required Chromium QA at 320/390/420px and desktop plus a real Home Assistant owner check. Current mobile modal stacking and English-only Back arrow behavior supersede its old RTL presentation. [Final acceptance](../G6_FINAL_STABILIZATION.md).
