# XPENG Vehicle Card v1.0.3 — G6 responsive dashboard and controls

Stable Home Assistant FRONTEND card update. No changes to the Xpengtk backend integration.

## What's new

- Same dashboard code automatically adapts to computer, phone and narrow HA Sections.
- Eight small G6 Home actions: A/C, Charging, Lock, Windows, Charge Port, Tailgate, Maintenance and Location.
- One-tap state-aware Lock, Windows, Charge Port and Tailgate commands, with live telemetry and Access permission safeguards; uncertain state disables actions.
- Native location popup on desktop and mobile, using the actual vehicle tracker on HA's dark map, with Horn / Flash and Back.
- Owner-supplied G6 light and dark cabin WebP photos, both front-seat heating/ventilation, independent rear-seat heat, wheel heat, actual temperature/fan features and available AUTO feedback. AUTO or airflow is interactive ONLY when corresponding writable HA climate modes exist.
- Charging keeps the original blue lakeside metrics layout, with a front G6 cutout and glowing cable. Exactly two new charging shortcuts: Charge limit and read-only Schedules.
- Maintenance groups four tire-pressure readings, odometer, next service and masked VIN.
- One Back navigation on all subpages; updated Hebrew/English interface labels and [Hebrew guide](../G6_DASHBOARD_GUIDE_HE.md).

## Quality assurance

All maintained source / dist, HACS, vehicle art and browser tests passed on consolidated G6 source. 24 Chromium screenshot captures cover desktop, phone and Sections widths, including a desktop Location test.

**Real-map and vehicle limitations:** The standalone desktop Location screenshot uses a labeled map test stub; genuine HA map tiles appear only inside Home Assistant. No real XPENG commands have been executed. The charging car cutout and decorative cable are not pixel-identical to the owner's cinematic charging reference.

## HACS update

In Home Assistant HACS update the XPENG Vehicle Card to v1.0.3, refresh frontend resources, keep your correct vehicle prefix and cabin finish. Enable Access actions only if desired and supported in Xpengtk. Check map GPS, Horn, Flash, Tailgate and cabin controls on the real car.
