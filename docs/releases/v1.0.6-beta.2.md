# XPENG Vehicle Card v1.0.6-beta.2 — Grouped Electrical Metrics

HACS prerelease for owner review. Stable v1.0.5 and beta.1 remain unchanged.

- All electrical measurements are grouped together in the **first row**: Charging power (kW), Current (A), Voltage (V).
- **Second row:** Time remaining and Charge limit, visually separated from electrical readings.
- Replaced the misleading speedometer for Voltage with an official MDI **V** symbol, and added an official MDI **A** symbol for Current.
- Missing/invalid current and voltage still display **0.0 A** and **0.0 V**. This is a display fallback, not a measured zero.
- Retains original battery percentage, range, vehicle artwork, station, charging cable, and three charging action buttons.
- Real Chromium QA validates desktop and iPhone layout, car clearance, and metric grouping.

Install via HACS → XPENG Vehicle Card → Redownload → Need a different version? → `v1.0.6-beta.2`. Refresh the frontend.

This is a preview release. No changes to the stable v1.0.5 tag.
