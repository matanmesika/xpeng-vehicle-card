# XPENG G6 Dashboard v1.0.4-beta.21 — Stabilization + Photographic Charging Station

**Type:** opt-in prerelease. **Owner review required.** Stable `main` remains unchanged.

## Changes
- Replaced the retired hand-drawn charging pedestal with a transparent WebP crop of the owner-approved photorealistic XPENG station concept. The image is embedded directly into the distributed JS bundle, so standalone installation works without downloading another asset.
- Preserved the existing XPENG G6 vehicle image, approved night lakeside background, state-driven battery display and all car controls.
- Kept the charging cable separate from the station art: the same live-status dynamic green cable remains attached to the existing charging port and works on desktop and iPhone.
- Retained the already tested post-Beta-19 stabilization improvements: corrected desktop Back alignment, Climate shortcut hover, circular More Options hover, English-only labels, Software Updates explanation, GPS map recentering on opening, mobile modal layering and TPMS glyph order.
- This is **not** the final charger placement. Desktop station position and iPhone panel/car/station layers require the owner's visual approval after installing this Beta.

## Automated release gates
- Full Frontend/HACS/vehicle artwork metadata and JavaScript/regression tests.
- Real Chromium render checks: the embedded WebP must decode, the station replaces the previous illustrated SVG, and the G6/cable/charging dashboard remain operational.
- A refreshed fourteen-file real-browser screenshot gallery at `docs/screenshots/` (simulated Home Assistant sensor values only).
- No merge to stable `main` and no changes to existing published Beta tags.

## Owner test
1. Download and install this opt-in prerelease with HACS and clear any frontend cache.
2. Open the actual Charging scene on desktop and iPhone. Check the new station's height and horizontal placement.
3. Verify the thin green cable reaches the real vehicle charge-port location and does not obstruct charging stats.
4. Confirm Back, More Options, Climate, Software Updates, TPMS and map opening still behave as expected.
5. Send desktop/iPhone screenshots with exact alignment instructions for the next placement-only revision.

**Limitation:** photos and recorded Chromium browser captures do not prove that vehicle commands execute; this requires a live Home Assistant test.
