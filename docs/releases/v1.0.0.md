# XPENG Vehicle Card v1.0.0

Initial stable dashboard release. **Frontend only** — this is not the XPENG account integration.

- Model selector sorted by latest available model year; model years shown individually, newest first, without duplicated or mixed-year choices.
- Exact model-year exterior palettes and correct body-generation artwork routing, including backward compatibility with existing legacy group configurations.
- Home Assistant HACS-compatible read-only vehicle and charging dashboard, including mapped sensors and tyre pressure detail.
- Repository root simplified to README.md, LICENSE and hacs.json (plus hidden Git configuration and directories).

**Artwork availability:** the full model/year/paint catalogue is supported as selectable metadata, but not all combinations have finished vehicle renders. Missing images use labelled illustrative fallback; manufacturer accuracy is not guaranteed.
