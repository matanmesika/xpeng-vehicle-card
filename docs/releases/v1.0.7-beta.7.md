# v1.0.7-beta.7

Opt-in beta for XPENG G6 dashboards using Xpeng Toolkit.

## Changes

- Keep the green live lead physically continuous with the black cable emerging from the vehicle charging connector.
- Align the lead to the charging cable connection on the XPENG station.
- Move and reduce the charging page heading so it stays clear of the telemetry panel.
- Compact and reposition the phone charging panel without covering the vehicle.
- Continue supporting unified Xpeng Toolkit covers and separate per-action sensors/buttons for the trunk, windows, and charge port.
- Display AC current separately from the vehicle battery charge limit.

## Install

In HACS, open **XPENG Vehicle Card → Redownload → Need a different version?** and choose **v1.0.7-beta.7**. Reload the Home Assistant frontend after installing. This is an opt-in prerelease; v1.0.6 remains the stable release.

## Compatibility

Requires a separately configured Xpeng Toolkit Home Assistant integration. Controls appear only when the relevant entities are available. The charging display uses the integration's reported telemetry and does not verify commands at the vehicle.
