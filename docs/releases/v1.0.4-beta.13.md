# XPENG Vehicle Card v1.0.4-beta.13 — G6 V3 Glass UI Preview

This **prerelease** packages the owner-reviewed V3 design branch without merging it to `main`.

## What's included
- New floating, translucent circular action buttons; no heavy rectangular backing cards.
- Proportional official Material Design Icons: approx. 19–23px icon glyphs inside 42–48px circular controls, adjusted to the current card width.
- Updated Home, automatic Charging, HVAC/climate, Maintenance/TPMS, Custom Functions, Map and Diagnostics styling.
- Consistent desktop, Home Assistant Sections and iPhone sizing through a single responsive card.
- Original approved lakeside night background, owner vehicle imagery and interior colour selection preserved.
- Verified Home Assistant entity mappings, genuine seat/wheel controls, lock/windows/trunk/port commands, charge limit, X-Guard, and native map unchanged.
- 14 genuine automated Chromium screenshots under `docs/screenshots/` (using **demonstration sensor states**, not a live vehicle).

## QA
- Full G6 pre-merge acceptance and eight specialist design review jobs passed on the source candidate.
- Frontend, HACS and vehicle artwork validations passed.
- This prerelease is **not a certification of live XPENG commands, GPS/map tiles, or iOS Safari behaviour**. Test on your actual Home Assistant installation before approving stable.

## Known item for owner review
- Maintenance still contains service and vehicle identity details below the tire-pressure section. A TPMS-only layout was requested and remains to be finalised.
- Frontend design reviewed using Chromium and simulated entity data.

## How to install with HACS
1. HACS → Frontend/Dashboard → XPENG Vehicle Card.
2. Open the card menu → Redownload (or Reinstall).
3. Choose **Need a different version?** and select `v1.0.4-beta.13`.
4. Reload Home Assistant and hard refresh the dashboard/client to ensure the new JS is used.
5. Check dashboard, charging transition, HVAC seats, maintenance, advanced functions and location with your live data.

The stable `main` branch and stable release are unchanged.
