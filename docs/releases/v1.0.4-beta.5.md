# v1.0.4-beta.5 — Phone scrolling, action feedback and native map stability

Historical opt-in prerelease incorporating Beta 1–4. Improved state-preserving iPhone sensor updates without rebuilding the entire Shadow DOM, maintained page scroll position and focus, serialized repeated lock/action taps while waiting for vehicle feedback, and reused the native Home Assistant map card across GPS sensor updates. Added a location details fallback and extended simulated Xpengtk regression coverage.

No real vehicle action or location was verified by CI. The stable `main` branch remained unchanged and real Home Assistant acceptance was required.

Use HACS Redownload to select `v1.0.4-beta.5` if historic rollback is necessary. [Current release criteria](../G6_FINAL_STABILIZATION.md).
