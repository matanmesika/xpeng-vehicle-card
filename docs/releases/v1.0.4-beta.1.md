# XPENG Vehicle Card v1.0.4-beta.1 — בדיקת Home Assistant אמיתית

**גרסת בטא ניסיונית בלבד.** אינה גרסה יציבה, וטרם אומתה פיזית ברכב XPENG G6. הקוד כולל את שינויי PR #44 ונועדה לבצע בדיוק את בדיקת החיישנים והתמונות בסביבת Home Assistant של המשתמש. v1.0.3 היציבה נשמרת כמות שהיא.

## מה השתנה
- אותו כרטיס Lovelace מסתגל אוטומטית למחשב, לטלפון ול־Home Assistant Sections צר, כולל הקטנת אובייקטים פיזית במסך.
- מעבר אוטומטי למסך טעינה רק כשהחיישן החי מדווח טעינה, חזרה למסך הרגיל בסיום או בניתוק מאומת.
- מסך הטעינה מציג רכב מוקטן, עמדת טעינה, כבל ירוק בזמן טעינה ו**את אותם שבעת כפתורי הרכב** כמו מסך הבית.
- 3 בקרות טעינה: הגבלת אחוזים באמצעות ישות number אמיתית, תזמון לקריאה בלבד, ועצירת טעינה רק אם ישות button רלוונטית קיימת (פקודה רגישה עם אישור).
- מפה דרך כרטיס המפה של Home Assistant בפועל, חיווי GPS ומיקום; כפתורי צופר/הבהוב רק כשיש שירות תואם.
- חיישני חלונות, דלתות, נעילה, שקע טעינה וארבעת הצמיגים ממופים מול Xpengtk/Entity Registry, תוך מניעת ניחוש רכב אחר.
- מסך מיזוג עם לחיצות על מושב/הגה רלוונטיים בלבד, כפתורי חימום/אוורור מוצגים רק לישויות נתמכות; תמונות הפנים המקוריות בהיר/כהה נבחרות בהגדרות הכרטיס.
- נשמר רקע האגם הלילי, תמונות הרכב והקבצים המקוריים; צילומי בדיקות ישנים הוסרו. ייצור 12 תמונות הדפדפן נעשה מנתוני HA **מדומים** — לא צילום של רכב מחובר.

## התקנה — HACS
1. בממשק Home Assistant פתחו HACS → XPENG Vehicle Card (מאגר מותאם אישית https://github.com/matanmesika/xpeng-vehicle-card , סוג Dashboard).
2. בחרו בתפריט ⋮ → Redownload → Need a different version? → `v1.0.4-beta.1`. אם גרסאות Beta אינן מופיעות, יש להפעיל אפשרות/ישות Enable pre-releases עבור המאגר ב־HACS.
3. רעננו את דפדפן/אפליקציית Home Assistant (ולפי הצורך נקו cache לקובץ ה־JS) ובדקו שהגרסה החדשה נטענה.
4. הבטא מתאימה לבדיקה במערכת מקומית **עם Xpengtk מחובר**; לא נדרש לגעת בקוד האינטגרציה המקורית.

## בדיקת המערכת האמיתית
המדריך המלא: [`docs/G6_BETA_LIVE_ACCEPTANCE_HE.md`](../G6_BETA_LIVE_ACCEPTANCE_HE.md).

בדקו במסך החיישנים ב־Home Assistant והתצוגה בו־זמנית: מצב טעינה/כבל, אחוז סוללה, דלתות, חלונות, נעילה, שקע טעינה, ארבעה לחצי צמיגים ונתוני מיזוג. בצעו בדיקה מבוקרת של טעינה אמיתית מול עמדת טעינה ובדקו מעבר למסך טעינה, כבל ירוק וחזרה למסך בית. פקודות רגישות רק במצב בטוח, עם אישור המשתמש והרשאות מתאימות.

## בעיות ומגבלות מכוונות
- תמונות בדיקות ב־GitHub נוצרו בדפדפן עם חיישנים מדומים; הבטא תציג את **חיישני Home Assistant האמיתיים** שלכם.
- שינוי תזמון טעינה / שחרור כבל טעינה / AUTO בלתי נתמך לא יגרמו לפקודות מומצאות.
- המפה דורשת ישות device_tracker אמיתית; ב־CI מוצג placeholder בלבד.
- עדיין נדרש משוב על התאמת תצלום הרכב/צבע/דגם לתמונות הייחוס (GitHub issue #14).
- בטא זו אינה מבטיחה שכל פקודה נתמכת בגרסת Xpengtk שמותקנת אצלכם.
