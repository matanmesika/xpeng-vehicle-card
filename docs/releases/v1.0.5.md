# XPENG Vehicle Card v1.0.5 — Stable

Stable release for HACS, following v1.0.4. This release includes the tested G6 climate, charging and communication-display improvements previously previewed in v1.0.5-beta.3.

## Changes
- Seven new **read-only** Climate status tiles: Max Cooling, Max Heating, Rear Defrost, Air Refresh, Sterilisation, A/C Cleaning and Pet Mode.
- Shared fan-speed bar styling across desktop and mobile Climate layouts.
- Current (A) and Voltage (V) in the **existing** Charging view, beneath charging power, remaining time and charge limit. No duplicate controls.
- The existing Wi-Fi button now distinguishes **connection state** (MQTT when that sensor is mapped, otherwise integration connection) from **vehicle data freshness** (Recent / Old / Unknown). The popover includes data age and the last vehicle update timestamp.
- The Wi-Fi icon flags old data in amber and unknown freshness in neutral when the transport is connected; disconnected and error states retain their own appearance.
- Responsive layout improvements to keep the vehicle and charging controls visible.

## Freshness interpretation
- **Recent:** mapped vehicle timestamp is no more than 2 hours old.
- **Old:** mapped vehicle timestamp is older than 2 hours. A parked or sleeping vehicle may legitimately show Old.
- **Unknown:** the timestamp is missing, unavailable or invalid.
- An MQTT connection does **not** prove the car sent new data. Home Assistant entity `last_updated` is not treated as a vehicle refresh.
- This is display-only and does not change the underlying XPENG integration's polling, wake-up logic or location updates.

## Install
HACS → XPENG Vehicle Card → Redownload (or Update) → select **v1.0.5**. Refresh the Home Assistant frontend after updating.

## Verification
Release automation validates the generated bundle, HACS metadata, maintained regression tests, real Chromium desktop/mobile screenshots and vehicle artwork audits before publishing. Live readings and update freshness should still be verified with the owner's own Home Assistant sensor entities.
