# XPENG Vehicle Card v1.0.8 — Stable

Maintenance release for the HACS page.

## Changes
- The official XPENG logo now appears at the top of the README / HACS page.
- The logo is stored in this repository (`assets/brand/xpeng-logo.svg`) on a light tile, so it stays readable in both light and dark Home Assistant / HACS themes.
- README release links updated (stable v1.0.8, previous stable v1.0.7).

## Card
No code changes. `dist/xpeng-vehicle-card.js` is identical to v1.0.7, including the continuous charging cable.

## Notes
- The XPENG logo is used only to identify supported vehicles. This is an unofficial community project, not affiliated with XPENG Motors. See `docs/TRADEMARK.md`.
