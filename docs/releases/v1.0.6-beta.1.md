# XPENG Vehicle Card v1.0.6-beta.1 — Integrated Charging Metrics

HACS prerelease for owner review. Stable v1.0.5 remains unchanged.

- Current (A) and Voltage (V) are now **two full metric cells within the same charging measurements grid**, not a detached text row.
- The existing Charging power, Time remaining and Charge limit metrics remain in the first row. Current and Voltage use matching typography, icons, and separators in the second row.
- Missing/invalid current or voltage is displayed as **0.0 A** or **0.0 V**. This is a display fallback, not a measured value.
- The three charging action buttons, car/charger/cable visuals, and other sensor fallback behaviors are unchanged.
- Desktop and iPhone responsive layout verified by automated real-Chromium tests.

Install via HACS → XPENG Vehicle Card → Redownload → Need a different version? → `v1.0.6-beta.1`. Refresh the frontend.

This is a preview release; no changes to the stable v1.0.5 tag.
