# XPENG G6 — גלריית בדיקות עדכנית

הגלריה מכילה **12 צילומי דפדפן אמיתיים** של רכיב `xpeng-vehicle-card` בענף הבדיקות הנוכחי, ולא הדמיות AI. ערכי חיישנים בצילומים הם **נתוני הדגמה בלבד**; אין חיבור לרכב אמיתי. צילומי המפה מציגים מציין־מקום לבדיקה ולא מפה חיה.

הכפתורים **נעילה, חלונות, תא מטען ושקע טעינה** הם פעולות ישירות במסך הבית, ולכן אין להם צילומי "עמוד" נפרדים. הכפתורים נשארים גלויים בצילומי הבית.

## ניהול התמונות

- ההפקה מתבצעת באמצעות `scripts/capture-dashboard.cjs` עם Playwright ו־Chromium.
- בכל הפקה התמונות הישנות בתיקייה זו מוחלפות ב־12 הצילומים הנוכחיים בלבד. תמונות הרכב ב־`assets/vehicles/` והרקע המקורי **אינן נמחקות**.
- הקבצים בתיקייה הם לצורכי סקירת ממשק לפני מיזוג; הם אינם תחליף לבדיקות על Home Assistant והרכב האמיתיים.

## הפקה מחדש — 18.10.2026

הגלריה הישנה נמחקה לפני הרצת צילום חדשה. המערכת יצרה מחדש את **12 הצילומים** מתוך קוד הרכיב המעודכן בענף זה, בעזרת Playwright/Chromium ונתוני Home Assistant לדוגמה. Commit של ההפקה: [`2f162ff8`](https://github.com/matanmesika/xpeng-vehicle-card/commit/2f162ff8dbf6417a4fa3fb2bf44fbe5fd69edf18).

הקבצים החדשים מיועדים לאישור חזותי בלבד. התאמת החיישנים והפקודות ל־XPENG אמיתי מחייבת בדיקה בהתקנת Home Assistant של בעל הרכב. אין מיזוג או פרסום אוטומטי בעקבות רענון התמונות.
