# Original assets and third-party independence

This project is an **unofficial community project** for XPENG vehicles. It is not produced, endorsed, or authorized by XPENG.

## Project policy

- Use only independently authored frontend code and graphics created or properly licensed for this project.
- Do not import assets, logos, screenshots, JavaScript, CSS or SVGs from unrelated vehicle dashboards merely because their layout is a useful reference.
- A general UI arrangement, such as a home view with separate charging, climate and controls screens, is not a dependency on any other integration.
- Exterior and interior visualizations are illustrations. They are not represented as manufacturer-supplied or factory-accurate photographs.
- Product and brand marks belong to their respective owners. Review the distribution rights for every third-party asset prior to a public stable release.
- Report any suspect file or provenance concern through a GitHub issue so it can be reviewed and, where necessary, replaced.

## Repository check

The automated brand-independence test detects borrowed-name references and vendor-specific filenames in source, documentation and SVG markup. It cannot prove the visual provenance of binary images, so image review remains a separate release requirement.
