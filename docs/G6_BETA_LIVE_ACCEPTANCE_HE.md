# XPENG G6 — פרוטוקול בדיקת בטא ב־Home Assistant אמיתי

גרסה: **v1.0.4-beta.4**. מיועד לבדיקה על רכב המשתמש בלבד. תוצאות GitHub/Playwright אינן בדיקה פיזית. אל תשלחו VIN מלא, כתובת מדויקת, קואורדינטות GPS, או מפתחות/טוקנים.

## מה השתנה בבטא 2
- כותרות חלונות המשנה מציגות רק את שם החלון, בלי לחזור על G6 בכל חלון.
- מעבר למשל ממיזוג לתזמון מיזוג ושימוש בחזרה מחזירים למיזוג, כולל מיקום הגלילה הקודם.
- אפשרויות נוספות → אבחון חיישנים → חזרה מחזיר ל'אפשרויות נוספות' ורק חזרה נוספת למסך הבית.
- שינוי גוון תמונת הפנים בהגדרות הכרטיס אינו סוגר את חלון המיזוג הפתוח.

## תיקונים חדשים בבטא 3
- [ ] תחזוקה דרך גלגל השיניים פותחת בדיוק את מסך התחזוקה, עם ארבעת הגלגלים, בלי שכפול בפריסה
- [ ] אבחון הישויות גולל כעמוד אחד בטלפון (בלי אזור פנימי שכולא מחוות)
- [ ] בזמן שהטלפון גולל במיזוג או באבחון, חיישנים מתעדכנים מבלי להחזיר את המסך למעלה
- [ ] המפה של Home Assistant אינה נעלמת או מהבהבת עם שינוי SOC/חיישנים; מאשרים זאת רק מול מפת HA אמיתית
- [ ] סמל הקישוריות מיושר בכותרת במחשב; אייקוני חלונות ותא מטען החדשים מוצגים נכון
- [ ] בשורת שנת דגם מופיע מקור: "מהאינטגרציה" אם `sensor.vehicle_identity.attributes.model_year` קיים; אחרת "מהגדרות הכרטיס"
- [ ] אין להציג שנת דגם מהגדרות הכרטיס כאילו אומתה מול הרכב

## בדיקות אייקונים וניווט — בטא 4
- [ ] ודאו שכל שבעת סמלי הבית מופיעים כמפות MDI אמיתיות (ללא ריבועים/סימני שאלה) במחשב ובטלפון
- [ ] סמלי נעילה/חלונות/תא מטען משתנים בהתאם למצב החיישנים; שינוי חזותי אינו משנה פעולת רכב
- [ ] אייקונים בתפריט הגדרות, מיזוג, סוללה, צמיגים, טעינה ומפה מיושרים ומודרניים
- [ ] בכל עמוד — רק לחצן חץ ימינה חזרה (RTL), בלי טקסט גלוי; הוא עדיין מחזיר למסך הקודם
- [ ] חזרה מתזמון מיזוג מחזירה למיזוג, ושומרת מיקום גלילה
- [ ] לא השתנו הרקע, תמונות הרכב או תמונות פנים הרכב
- [ ] הסמל על עמדת הטעינה מוצג כ־MDI EV Station, ולא כתב X דקורטיבי

## א. אימות התקנה
- [ ] HACS מציג v1.0.4-beta.4; בחרו `Redownload → Need a different version?` אם צריך.
- [ ] לאחר רענון קשה של הדפדפן/אפליקציה מוצגים התפריטים החדשים והמסך נפתח ללא שגיאות.
- [ ] פתיחת מסך הבית במחשב, בטלפון וב־Sections צר; כל שבעת הכפתורים מוצגים גם במסך טעינה.
- [ ] בדיקת גלילה במסכי מיזוג, תחזוקה ומפה בטלפון אמיתי; אין חפיפת לחצנים/גלילה אופקית.
- [ ] צלמו מסך בית, מסך טעינה, חלון מיזוג ותצוגת הצמיגים **מתוך Home Assistant המותקן שלכם**, לא מצילומי GitHub.

## ב. מצבי חיישנים (קריאה בלבד)
היכנסו ל־Developer Tools → States. בדקו את **הישות שבאמת קיימת אצלכם** במקום להסתמך על קידומת לדוגמה; ניתן לזהות דרך Settings → Devices & Services → Entities ולסנן XPENG/Xpengtk.
- [ ] סוללה (`battery`/`battery_soc`), טווח (`range`) ו־`charge_power` משקפים את מה שהרכב מציג.
- [ ] `charging` ו־`plugged_in` תואמים את מצב הכבל והטעינה בפועל; מצב `unknown` או `unavailable` אינו נחשב טעינה פעילה.
- [ ] `driver_door`, `passenger_door`, `rear_left_door`, `rear_right_door` משתנים עם פתיחת דלת רלוונטית (בדיקה בעמידה בלבד).
- [ ] מצב נעילה (`door_lock` או `locked`) ברור ומדויק.
- [ ] `any_window_open`/`windows` משתנה כשפותחים וסוגרים חלון.
- [ ] `slow_charge_port` מציג `Closed`, `Open` או `Connected` לפי המצב; בזמן חיבור כבל אסור לקבל אפשרות לסגירת הדלתית.
- [ ] ארבעת חיישני `tyre_pressure_front_left`, `front_right`, `rear_left`, `rear_right` מציגים ערכים סבירים ליד כל גלגל. בדקו bar/PSI/kPa רק בהגדרות הכרטיס.
- [ ] מפת המיקום משתמשת ב־`device_tracker.location` של הרכב שבחרתם. אל תשתפו צילום עם מיקום או כתובת.

## ג. בדיקת טעינה אמיתית
- [ ] לפני חיבור: מסך הבית מוצג, עם כל 7 הפעולות.
- [ ] בזמן טעינה פעילה: תצוגת הטעינה מופיעה **באופן אוטומטי** (ללא לחצן מעבר ידני).
- [ ] בדקו שהתמונה היא של הרכב והצבע הנכונים (ושמרה את תמונת הטעינה המקורית) וכי העמדה גלויה.
- [ ] כבל ירוק רציף ממחבר הרכב לעמדת הטעינה, בלי לחסום את שורת הפעולות.
- [ ] כל שבעת כפתורי הבית מופיעים גם בטעינה ופעולות מיזוג/מיקום/תחזוקה פותחות חלון בתוך הכרטיס.
- [ ] שלושת כפתורי הטעינה: הגבלה (סליידר `number.charge_limit_control`), תזמון (מידע לקריאה בלבד), עצור (מופיע וזמין רק אם קיימת פקודת stop_charge).
- [ ] בסיום הטעינה/ניתוק בטוח: הממשק חוזר אוטומטית לבית והכבל הירוק נעלם.
- [ ] **אין לשלוח "עצור טעינה" במהלך בדיקה ללא אישור מפורש של בעל הרכב והבנת ההשלכה.**

## ד. בקרות רכב ומיזוג
- [ ] תמונות הפנים בהיר/כהה נבחרות בהגדרות הכרטיס — לא במסך המיזוג.
- [ ] לחיצה על מושב מסוים מפעילה רק את חימום/אוורור המושב שבחרתם; לחיצה על ההגה רק חימום ההגה (אם Xpengtk מספקת ישות כתיבה אמיתית).
- [ ] טמפרטורה ומאוורר משקפים קריאות HA בזמן אמת; AUTO מוצג כחיווי בלבד כשאין פקודת כתיבה.
- [ ] נעילה, חלונות, תא מטען ושקע טעינה ניתנים לשינוי רק אם מצבם ידוע וקיימת הרשאת Access מתאימה. **בצעו רק בנוכחות הרכב, כשהוא חונה, ללא נוסעים בסיכון.**
- [ ] ודאו שהמפה באמת נטענת בתוך HA ולא מציגה placeholder.

## ה. אם משהו אינו עובד
רשמו: שם המסך, המצב בפועל, מה ציפיתם לראות, זמן בדיקה, סוג תצוגה (iPhone/מחשב/Sections), ושם הישות יחד עם מצב `on/off/unavailable` בלבד. צילום מסך מתוך Home Assistant אמיתי מותר לאחר השחרת מיקום, VIN ושדות מזהים. אם הפקודה לא נמצאת באינטגרציה — אין להחליפה בפקודה מומצאת.

## ו. חזרה בטוחה לגרסה קודמת
HACS → XPENG Vehicle Card → ⋮ → Redownload → Need a different version? → `v1.0.3` → רענון אפליקציה/דפדפן. גרסת בטא אינה משדרגת/מחליפה את אינטגרציית Xpengtk עצמה.

**רק לאחר אישור משתמש על סמך בדיקות חיות** נסגור את בעיות החיישנים והתמונות; מעבר בדיקות CI לבדו אינו מספק.
