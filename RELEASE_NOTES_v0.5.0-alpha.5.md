# XPENG Vehicle Card v0.5.0-alpha.5 (experimental)

- Main visual switches with category: exterior, annotated doors and tires, cabin, charging overlay and location overlay.
- Full-window display works with browser native fullscreen where supported, and CSS viewport fallback on mobile. Exit button and Escape supported.
- Full-cabin color settings cover seats, wheel, dashboard, console and door panels.
- Displays read-only real HA entity state; unknown readings are unavailable.
- 16 profiles / 5 exterior paint choices / 2 interior finishes are visual previews, not certified model catalogues.
- No working direct XPENG account connection or remote commands are claimed.
- Source and dist JavaScript are packaged identically for HACS custom repository use.
